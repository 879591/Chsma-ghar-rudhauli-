**स्थान:** बस्ती-बांसी रोड, निकट भारत बैट्री, रुधौली-बस्ती, उत्तर प्रदेश

**खुलने का समय:** सुबह 9:00 बजे से शाम 6:00 बजे तक  
**हमारे विशेषज्ञ:** डॉ. N.S. शर्मा (`D.Opt`), डॉ. D.K. आर्या (`D.Opt`)

## 1. प्रमुख विशेषताएँ (Key Features)

1. **मोबाइल-फ़र्स्ट एवं प्रीमियम ऑप्टिकल डिज़ाइन:**
   - हिंदी भाषा प्रमुख (`Noto Sans Devanagari`) और सहायक अंग्रेज़ी (`Plus Jakarta Sans`)।
   - 360px से 1440px तक सभी Android, iPhone और डेस्कटॉप स्क्रीन के लिए अनुकूलित।
   - मोबाइल के लिए नीचे स्टिकी एक्शन बार (कॉल करें, WhatsApp, अपॉइंटमेंट)।

2. **ऑनलाइन प्रारंभिक दृष्टि जाँच (Interactive Eye Test):**
   - हिंदी (`क म र`) और अंग्रेज़ी (`E F P`) दोनों अक्षरों में 7-स्तरीय (`6/60` से `6/6`) विज़ुअल एक्युइटी स्क्रीनिंग।
   - फुल-स्क्रीन मोड, दाईं/बाईं आँख के लिए चरण-दर-चरण निर्देश और स्पष्ट चिकित्सा सुरक्षा अस्वीकरण।

3. **चश्मा कैटलॉग एवं फ्रेम गैलरी:**
   - श्रेणियाँ: Men's Frames, Women's Frames, Kids Frames, Sunglasses, Computer Glasses, Premium Frames।
   - फ्रेम गैलरी में सर्च, श्रेणी फ़िल्टर, लाइटबॉक्स ज़ूम, और मोबाइल स्वाइप सपोर्ट।
   - प्रत्येक कार्ड और फोटो से सीधे WhatsApp (`9118252405`) पर उपलब्धता और कीमत पूछने की सुविधा।

4. **प्रिस्क्रिप्शन (चश्मे का नंबर) PDF एवं ग्राहक डाउनलोड्स:**
   - दाईं आँख (`OD`) और बाईं आँख (`OS`) के लिए `SPH`, `CYL`, `AXIS`, `ADD`, `PD` और `Remarks` दर्ज कर तुरंत प्रिंट/PDF पर्ची डाउनलोड करें।
   - डिजिटल विज़िटिंग कार्ड (`.vcf` vCard), बिज़नेस कार्ड, अपॉइंटमेंट स्लिप और स्टोर QR कोड डाउनलोड।

5. **प्रोग्रेसिव वेब ऐप (PWA) एवं ऑफ़लाइन सपोर्ट:**
   - `vite-plugin-pwa` द्वारा सर्विस वर्कर, वेब ऐप मैनिफेस्ट, और ऑफ़लाइन कैशिंग।
   - हेडर और डाउनलोड सेक्शन में `"📲 ऐप इंस्टॉल करें"` और `"वेबसाइट शेयर करें"` (Web Share API) बटन।

6. **स्टोर एडमिन पैनल (CMS):**
   - फुटर में `"स्टोर एडमिन (Admin)"` बटन (डिफ़ॉल्ट डेमो पिन: `2405`)।
   - स्टोर का नाम, फोन नंबर, समय, सेवाएँ, डॉक्टर, फ्रेम कैटलॉग, गैलरी फोटो, और अपॉइंटमेंट रिकॉर्ड्स प्रबंधित करें।

## 2. लोकल सेटअप निर्देश (Setup Instructions)

```bash
# 1. डिपेंडेंसी इंस्टॉल करें
npm install

# 2. डेवलपमेंट सर्वर चलाएँ (Port 3000)
npm run dev

# 3. प्रोडक्शन बिल्ड तैयार करें
npm run build

# 4. बिल्ड का प्रीव्यू देखें
npm run preview
```

---

## 3. Vercel डिप्लॉयमेंट निर्देश (Vercel Deployment)

1. इस प्रोजेक्ट को अपने GitHub रिपॉजिटरी में पुश करें।
2. [Vercel](https://vercel.com) पर लॉग इन करें और **"Add New Project"** चुनें।
3. अपनी रिपॉजिटरी चुनें:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. यदि आप Supabase जोड़ रहे हैं, तो **Environment Variables** सेक्शन में नीचे दिए गए वेरिएबल्स जोड़ें और **Deploy** पर क्लिक करें।

## 4. PWA इंस्टॉलेशन निर्देश (PWA Installation)

- **Android (Chrome):** वेबसाइट खोलें और `"📲 ऐप इंस्टॉल करें"` बटन पर टैप करें।
- **iPhone / iPad (Safari):** वेबसाइट खोलें, नीचे **Share** आइकन पर टैप करें और **"Add to Home Screen"** चुनें।
- **Desktop (Chrome / Edge):** एड्रेस बार के दाईं ओर इंस्टॉल आइकन या हेडर में `"📲 ऐप इंस्टॉल करें"` पर क्लिक करें।

## 5. एडमिन सेटअप एवं वास्तविक फोटो अपडेट करना (Admin & Shop Photos Setup)

- **Local/Demo Mode:** फुटर में `"स्टोर एडमिन (Admin)"` पर क्लिक करें और पिन **`2405`** दर्ज करें। यहाँ से आप तुरंत कोई भी नया चश्मा, फ्रेम, सेवा या फोटो URL बदल सकते हैं।
- **दुकान के वास्तविक फोटो लगाना:** अपनी दुकान और साइनबोर्ड के वास्तविक फोटो `/public/shop-photos/` फ़ोल्डर में रखें और एडमिन पैनल के **फोटो व गैलरी** टैब से उनका पथ अपडेट करें।
- **Supabase Production Mode:** सभी उपयोगकर्ताओं के लिए केंद्रीकृत डेटाबेस जोड़ने हेतु Supabase में `store_config`, `products` और `appointments` टेबल बनाएँ और Row Level Security (RLS) सक्षम करें।
